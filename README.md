# HackMate – College Hackathon Platform 🚀

A modern, responsive web application for collegiate hackathons designed to help students discover problem ideas, assemble dream teams, and ship winning prototypes.

## 🌟 Key Features

- **🏠 Interactive Home Page**:
  - Live hackathon code-freeze countdown clock.
  - Real-time statistics counters (1,420+ Hackers, 340+ Squads, $45,000 Prizes).
  - 36-Hour Hackathon roadmap & timeline.
  - Competition tracks across AI, BioTech, Web3, Climate, and EdTech.

- **💡 Project Repository & Search**:
  - Real-time search across titles, descriptions, tech stacks, and open roles.
  - Segmented category filtering (AI/ML, HealthTech, Web3, CyberSecurity, Climate, etc.).
  - Detailed modal view with problem statements, solutions, and role vacancy counts.
  - "Post Your Project" modal with persistent local storage.

- **🤝 Teammate Matchmaker**:
  - Search collegiate hackers by skill, university, and role (Frontend, Backend, AI/ML, UI/UX, Mobile, Pitch Lead).
  - One-click squad invite modal.
  - Hacker directory profile publication.

- **🛠 Developer Toolkit & Resources**:
  - Verified starter boilerplates with one-click terminal clone commands.
  - Interactive Hackathon Judging Rubric Calculator (score out of 100).
  - The 3-minute winning demo formula & presentation playbook.

- **📬 Contact & Concierge**:
  - Interactive form with category routing (Mentors, Sponsors, Campus Ambassadors).
  - Expandable hackathon FAQ accordion.

- **Animations & Interactivity**: Motion

## 🚀 Getting Started Locally

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or above recommended)
- [Git](https://git-scm.com/)

### 2. Clone the Repository
```bash
git clone https://github.com/prajwal2351/hackmate-college-hackathon.git
cd hackmate-college-hackathon
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port indicated in your console) in your browser.

### 5. Build for Production
```bash
npm run build
npm run preview
```
